> 版本：v3.1.0 - 2026-08-27 - Unclecow
> 定位：经典模式（Battle City 1:1 复刻）+ 生存模式（WAR3 基地防守 RTS 重做）的完整设计规格
> 关联文档：DESIGN_高台生存模式_v2.md（被本方案取代，归档至 pdoc/archive/design/）

---

## 0. 背景与目标

当前 `e:\坦克大战3D` 工程已实现三模式（classic / survival / td）雏形，但存在两类核心问题：

1. **经典模式未还原**：地图为程序生成，未复刻原版《坦克大战》（Battle City / 坦克大战 1990）的固定关卡布局。
2. **生存模式不达标**：原"高台+造塔"雏形与"魔兽 RPG 生存防守"差距大，操作/系统/UI/HUD 均需重做。

本方案目标：

- **经典模式**：1:1 复刻原版 35 关固定布局，保留既有 WASD+鼠标操作手感。
- **生存模式**：彻底重构为 **WAR3 风格基地防守（RTS 建造 + 塔防）**，含 RTS 自由镜头、魔兽式建造面板、建筑升级/摧毁、金矿经济、科技树解锁、多口生成单入口寻路、墙破即输。
- **资产**：地图全部使用 Kenney 模型（全量），HUD 仍为 CSS（ui/ 目录无 Kenney 资源）。

## 1. 经典模式重做（Battle City 1:1）

### 1.1 地图来源与格式 - v3.1.0
- 不追求原版 35 关逐关精确复刻；改为手工设计 **10 张具有 Battle City 风格的固定布局**（砖墙迷宫 + 钢墙 + 河流 + 树林 + 中央老鹰），随机选用。
- 每图编码为 **13×13 区块**二维数组（原版地图为 13×13 砖块格，每格 16px）。
- 瓦片图例（单字符）：

  | 字符 | 含义 | 引擎映射 |
  | :--- | :--- | :--- |
  | `B` | 砖墙（可破坏） | T_BRICK |
  | `S` | 钢墙（不可破坏，部分关卡可） | T_STEEL |
  | `W` | 河流（阻断坦克，可挡子弹） | T_WATER |
  | `T` | 树林（隐蔽，不挡子弹） | T_TREE |
  | `E` | 老鹰基地 | T_BASE |
  | `.` | 空地 | T_EMPTY |

- 老鹰固定位于 **底部正中（row 12, col 6）**，四周默认包裹砖墙（与原版一致）。

### 1.2 玩法推进（波次制，无"关"概念） - v3.1.0
- 开局**随机**从 10 张图中选一张作为本局地图（无顺序通关 / 选关）。
- **波次制**：敌人按波生成进攻，逐波增强（沿用 wave 计数与 enemyCount 逻辑）。
- 胜利条件：达成 `victoryWave` 后清场（或无尽模式）。
- 失败条件：老鹰（T_BASE）被击毁，或己方生命耗尽（保留既有 lives 逻辑）。

### 1.3 渲染与资产 - v3.0.0
- 砖墙 → `roads/construction-barrier` 或 `commercial` 小构件（保持可破坏碎裂观感）；钢墙 → `castle/wall-narrow`；河流 → `nature/bridge_center_wood` 平铺或 `roads/tile-low`；树林 → `nature/tree_*`；老鹰 → `castle/gate`（标识性）。
- 尺寸换算：原版 1 区块 = `TILE×TILE`（即 4×4 世界单位），13 区块 → 52×52 世界，居中放置。

### 1.4 操作（保留） - v3.0.0
- WASD 移动、鼠标瞄准射击、ESC 暂停。不做改动。

## 2. 生存模式重做（WAR3 基地防守 RTS）

### 2.1 地图结构 - v3.0.0
- 网格 `GRID = 47`（沿用），世界坐标左下角为地图原点参考。
- **主基地**：`commercial/skyscraper-a` 置于**左下角**固定格（如 col 3, row 3），为不可移动建筑，本身不被直接攻击。
- **单一入口 + 单一墙**：基地外围由玩家/预设构成**一道围墙 + 一个大门（Gate）**，仅留**一个入口**。入口处一道 `castle/metal-gate` 或 `wall` 段即"墙"，破即输。
- **敌军生成点**：地图远端（右上及两侧）设 **2~3 个 spawn 口**，但所有敌人共享**唯一目标 = 基地单一入口的墙/门**。

### 2.2 敌军 AI 与寻路 - v3.0.0
- 敌人类型为地面坦克/单位，从 spawn 口生成后**统一寻路至基地入口墙**。
- 寻路策略（轻量）：
  - 计算到入口墙的**直线/网格路径**（BFS 或直线+避障），路径上若遇到玩家建造的墙/塔则攻击之。
  - **目标优先级**：最近的可破坏阻挡（墙/塔/门）→ 若阻挡被清除则继续推进 → 抵达入口墙后攻击入口墙。
  - 入口墙 HP 归零 → **游戏结束**。
- 不要求完美 A*，采用"朝目标方向推进 + 遇阻攻击"的简化行为树即可，性能优先。

### 2.3 建筑体系（玩家可建造） - v3.0.0
底部魔兽式建造面板，按类别分组。建筑放置于空地格（点击面板项 → 鼠标预览 → 点击地面落位 → 扣费）。

| 建筑 | 费用 | 作用 | Kenney 模型 | 解锁条件 |
| :--- | :--- | :--- | :--- | :--- |
| 金矿 Mine | 70 | 周期产金（tier 升级提高产量） | `castle/rocks-small` 或 `commercial/building-a` | 初始 |
| 人口房 House | 50 | 提升人口上限（限制同时建筑/驻军数） | `commercial/building-b` | 初始 |
| 科技塔 Tech | 100 | 提供科技点，解锁更高级建筑 | `castle/tower-square-base` | 初始 |
| 机枪塔 MG | 60 | 基础攻击塔（射速快、伤害低） | `td/weapon-cannon` | 初始 |
| 墙 Wall | 20 | 阻挡敌军（有 HP，破即输关联） | `castle/wall-narrow` | 初始 |
| 大门 Gate | 40 | **唯一入口**：可升级血量/护甲并学习被动技能（详见 2.8）；HP 归零即输 | `castle/metal-gate` | 初始 |
| 加农塔 Cannon | 90 | 高伤慢射 | `td/weapon-cannon`（换色） | 科技 B1 |
| 寒冰塔 Frost | 80 | 减速 | `td/weapon-cannon`（换色） | 科技 E1 |
| 狙击塔 Sniper | 120 | 远程穿透 | `td/weapon-cannon`（换色） | 科技 C1 |
| 脉冲塔 Pulse | 140 | 范围 | `td/weapon-cannon`（换色） | 科技 D1 |
| 电磁塔 Tesla | 130 | 链击 | `td/weapon-cannon`（换色） | 科技 G1 |

> 注：塔的攻击逻辑沿用既有 `TURRET_TYPES`（mg/cannon/frost/sniper/pulse/tesla），仅将"科技树升级"改为"建造时按已解锁类型可选"。

### 2.4 经济与科技 - v3.0.0
- **金币**：金矿周期产出（tier 升级增产）；击杀敌人奖励；清波奖励。
- **人口**：人口房提升上限，建造建筑消耗人口（防止无脑爆塔）。
- **科技**：科技塔产出科技点；科技树分支（沿用 A~G 七系）**逐个解锁**更高级塔与升级项。初级仅机枪塔可用，其余随科技解锁。

### 2.5 操作（RTS 化重做） - v3.0.0
- **镜头**：WASD 平移镜头；鼠标拖拽（右键或中键）平移；滚轮缩放。取消坦克移动。
- **建造**：点击底部面板建筑项 → 地面出现半透明预览（绿=可放/红=不可放）→ 左键落位扣费。
- **选择/管理**：左键点选已有建筑 → 弹出操作环/面板：升级（花费）、摧毁（返还部分资源）。
- **快捷键**：数字键 1~9 对应建造面板项；Q/E 切换镜头；空格暂停。

### 2.6 HUD（魔兽风格） - v3.0.0
- **底部建造面板**：横排建筑图标（图标用 CSS 绘制 + 模型缩略），显示费用/解锁状态，未解锁置灰。
- **顶部资源条**：金币、人口（当前/上限）、科技点、当前波次/总波次、基地墙 HP 条。
- **小地图**：右上角 minimap（沿用），标注基地、spawn 口、敌军点。
- **多面板记分板（multiboard 风格）**：侧栏显示 波次进度、击杀数、漏怪数（墙损）、下一波倒计时。
- **提示/公告**：沿用 #announce / #hint，文案改为 WAR3 风格（"第 X 波进攻来临！""基地大门告急！"）。

### 2.7 胜负 - v3.0.0
- **胜利**：达成 `victoryWave`（如 15 波）后清场，或进入无尽模式。
- **失败**：入口墙/大门 HP 归零 → 立即 Game Over（"墙坏了就算输"）。

### 2.8 大门升级树（唯一入口的可成长结构） - v3.1.0
大门是基地唯一入口，本身即"墙"，其强度决定存亡。选中大门弹出升级面板，分两类：

- **基础属性（消耗金币）**
  - 血量（HP）：每级 +N，提升容错。
  - 护甲（Armor）：每级减伤百分比，降低每秒承伤。
- **被动技能（消耗科技点 / 金币，高阶解锁）**
  - 反伤（Thorns）：受击时按伤害比例反弹给攻击者。
  - 恢复（Regen）：每秒自动回血，对抗持续消耗。
  - 闪避（Dodge）：概率免疫一次伤害（不触发受击）。
  - （可选扩展：荆棘光环、护盾充能等）

> 设计意图：把"墙"从一个静态血量条，变成可经营成长的防御核心，呼应魔兽英雄/建筑的被动技能体系，提升策略深度与正反馈。

## 5. 风险与边界

- **经典 35 关数据准确性**：需从可靠来源获取原版关卡，逐关校对字符映射；若某关数据缺失，先用程序生成近似版并标注。
- **敌军寻路性能**：47×47 网格多单位 BFS 需节流（每 N 帧重算或事件触发），避免卡顿。
- **单入口墙破即输**：明确"墙"= 唯一入口大门；大门 HP 归零即 Game Over。大门可花金币升血量/护甲、学被动（反伤/恢复/闪避），避免一击猝死。
- **操作冲突**：WASD 由移动改为镜头后，需确保经典/td 模式不受影响（按 ACTIVE_MODE 分流输入）。
- **资产加载**：新增引用的 castle/gate 等需加入 `ASSET_FILES` 并验证加载，沿用 `_sharedGeoms` 防误 dispose。
