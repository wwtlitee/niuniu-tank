## 一、测试前置

1. 启动本地静态服务器（任选其一）：
   ```bash
   # 方式 A：Python
   cd e:\坦克大战3D
   python -m http.server 8000

   # 方式 B：Node
   npx http-server . -p 8000
   ```
2. 浏览器访问 `http://localhost:8000/index.html`
3. **必须使用 Chrome / Edge**（需 WebGL2 + ES Module 支持）
4. DevTools → Network → Disable cache；Console 保持开启

## 三、平衡性数据采集（30 波试玩）

### 3.1 试玩目标

- 完整跑 30 波，记录：
  - 累计击杀 / 漏防
  - 总金币收入曲线（每 5 波一个采样点）
  - 墙平均等级分布
  - 炮塔平均等级分布
  - 玩家死亡次数
  - 平均单波时长

### 3.2 平衡性红线（待调）

| 指标 | 红线 | 调整方向 |
|---|---|---|
| 通关率（30 波） | ≥ 40% | 若 < 40%：削敌血/移速 或 增塔伤害 |
| 平均漏防数 / 波 | < 2 | 若 > 2：增基础墙 HP 或 增塔射程 |
| 30 波时玩家金币 | ≥ 200 | 若 < 200：增金矿产量 / 增 killGold |
| 30 波时平均墙等级 | ≥ 2.5 | 若 < 2.5：降价 18/32 |
| 30 波时炮塔数 | ≥ 4 | 若 < 4：降塔基础价或人口成本 |

## 四、已知遗留风险（Agent 视角）

| 编号 | 描述 | 触发条件 | 建议 |
|---|---|---|---|
| R-1 | 墙升级瞬间 model 切换若异步加载会出现一帧空白 | 网络慢时 | 可加 fade 过渡 |
| R-2 | Lv5 金属门反伤 18% 可能让小怪自爆对玩家有利 | 大量小怪撞门 | 平衡期观察 |
| R-3 | 拆 Lv4 / Lv5 refund 较多（56/91），可能降低升级慎重度 | 玩家频繁拆建 | 平衡期可降至 30% |
| R-4 | 经典模式 buildWallTile(p,x,z,true) 老接口保留 | 切到经典模式测 | 若发现墙体异常需切回 v4.2 |
| R-5 | SkeletonUtils.clone 在 r128 用法：未在此次改动中涉及动画 | 仅用于敌人 | 若墙需加 idle 动画再启用 |
