> 说明：本文档为「高台生存」模式的完整玩法与实现方案。设计依据经典魔兽 RPG 生存图（《高地保安》《The Last Stand》《The Crossing》）与 TD 经济压力理论，并已确认三项关键分叉：**替换无尽幸存模式 / 实时运营 / 金矿+利息**。

---

## 一、业务背景与定位

现有 `endless`（无尽幸存）模式为大地图 + 自由构筑 + 无限成长，玩法偏「开放战场自由发挥」，运营决策点分散，长时间游玩易疲劳。

新「高台生存」模式剥离**开放自由度**，改为**单点咽喉 + 实时运营**的经典生存图：玩家坐落于高台，仅一条窄下坡出口，默认石墙封口留缺口，敌军只能挤过咽喉进攻。玩家在高台围绕「经济流水线」与「炮塔防御」做即时决策，坚持全部波次并击杀最终 Boss。

**核心爽点**（调研验证）：
- 单入口 = 最易防守 + 集中 kill zone（The Last Stand「绿点」原则）
- 控制塔 + 伤害塔协同（The Crossing「冰塔 + 死塔」原则）
- 存钱利息 vs 即时战力，每枚金币都要权衡（GemCraft/BTD 经济压力）
- 高台水晶毁坏触发 escalation，制造翻盘/崩盘张力（《高地保安》机制）

---

## 二、地图设计（核心差异点）

- 地图主体为一片**抬高的高台（plateau）**，占用图约下 1/2 区域，高度沿用引擎常量 `PH = 1.6`（复用 `T_PLATEAU` / `T_RAMP` / `rampDir` 上下坡驱动逻辑）。
- 高台**仅一条 1~2 格宽的狭窄下坡**通往下方战场，为唯一出口。
- 出口底部**默认预置钢制石墙（`T_STEEL`），正中留 1 格缺口**——玩家不建造墙体，缺口即咽喉 funnel。
- 高台为平整可建造区域；**核心建筑（鹰旗 / 水晶）** 置于高台中心偏后。
- 下方战场开阔，敌人从地图远端边界出生，向坡口集结、挤过缺口。

**模块级影响**：`genMap` 新增 `survival` 专用分支（不再套用城市网格生成），复用既有高地/坡道网格与建模。

---

## 三、核心循环（实时运营）

1. 游戏开始即进入**战斗 + 实时建造**双轨状态；商店面板可随时开启，关闭后继续战斗（借鉴《高地保安》实时性）。
2. 敌波从远端生成 → 沿战场向坡口推进 → 挤过缺口 → 登上高台 → 直扑核心。
3. 玩家坦克 + 高台炮塔在缺口/高台构成集中 kill zone 拦截。
4. 漏过缺口的敌人登上高台攻击核心；核心摧毁即败北。

**节奏设计**：无强制暂停的准备阶段；运营压力来自「波次间隙在战斗间隙抢建/升级」，而非静止的手游式等待。

---

## 四、经济公式（运营发展）— 单一资源「金币」

| 来源 | 规则 | 说明 |
| :--- | :--- | :--- |
| 击杀收益 | 沿用 endless：普通 10 / 快速 12 / 狙击 14 / 重装 22；精英 ×3；Boss 130 | 维持已有掉落逻辑 |
| 金矿（指挥中心） | 花金币建造，之后每波被动产金（如 +8/波，可升级） | 用「现在战力」换「未来现金流」 |
| 利息 | 每波结算时，持有金币按 ~10% 计息（设封顶，如 80） | 奖励存钱滚雪球，惩罚无脑 all-in |

**设计意图**：让「运营」本身成为决策核心——何时花钱加速、何时存钱吃利息，直接影响波次缺口。

---

## 五、防御公式（炮塔体系）— 无玩家石墙

复用引擎现有子弹 / 索敌 / EMP 眩晕 / 爆炸逻辑，提供 6 类建造物（仅塔 + 经济建筑）：

| 编号 | 塔 | 定位 | 3 级升级方向 |
| :--- | :--- | :--- | :--- |
| 1 | 机枪塔 | 廉价单体持续 DPS，开局主力 | 射速 / 伤害 |
| 2 | 加农炮塔 | AoE 溅射，清群 | 溅射半径 / 伤害 |
| 3 | 冰冻塔 | 范围减速（控制） | 减速幅度 / 范围 |
| 4 | 狙击塔 | 超远射程、高单体，打重装/精英 | 射程 / 穿透 / 伤害 |
| 5 | 脉冲塔 | AoE 眩晕（复用 EMP 机制） | 眩晕时长 / 范围 |
| 6 | 金矿（指挥中心） | 被动经济建筑 | 每波产金增幅 |

**布局策略**：缺口两侧密铺 = 集中 kill zone；玩家坦克在高台自由移动补刀 / 救火（塔为主、坦克为辅）。

---

## 六、波次与敌人

- 沿用 `ENEMY_TYPES`（normal / fast / heavy / sniper）+ 精英词缀 + BOSS，难度按 `difficultyScale` 递增。
- 特殊波：`rush`（大量快速）、`armored`（多重装）、`frenzy`（狂暴）。
- **终局**：守住 N 波（初版 12 波）后刷最终 Boss，击杀即胜利。

---

## 七、胜负条件

- **胜**：清完所有波次 + 击杀最终 Boss。
- **负**：核心（鹰旗 / 水晶）被摧毁。
- **escalation（借鉴《高地保安》）**：高台外围塔被清空 → 核心解除无敌并刷超级兵，制造翻盘或崩盘张力。

---

## 八、技术实现与集成

### 8.1 `js/config.js`
- 将 `endless` 模式改为 `survival`（`key: "survival"`）。
- 参数：
  - `GRID`（建议 41 或 47）、`cameraY` / `cameraZ`（俯视高台）、`fogFar`
  - `mapType: "survival"` 标志（用于 `genMap` 走专属分支）
  - `buildEnabled: true`、`buildTimer: 0`（实时运营，无倒计时）
  - `enemiesPerWave`、`spawnInterval`、`spawnCap`、`difficultyScale`、`goldStart`
  - 新增 `economy: { mineIncome, interestRate, interestCap }` 经济参数

### 8.2 `js/engine.js`
- `genMap` 新增 `survival` 分支：生成高台 + 单坡口 + 默认石墙缺口 + 核心点位；清空出生点周边，保证敌人可见路径。
- 商店 / 构筑系统：`renderShop` 使用 `survival` 专属 `shopItems`（仅 6 类塔 + 金矿，不含墙体）。
- 经济：注册金矿被动产金 + 波次结算利息逻辑（挂接 `finishBuild` / 波次推进处）。
- 核心受击：复用基地受击逻辑（`baseAlive` / `baseGroup`）绑定核心，被摧毁触发 `endGame`。
- 实时运营：关闭无尽模式的「B 键暂停商店」限制，改为可随时开面板但不暂停（或提供「暂停编辑」开关）。

### 8.3 `js/home.js`
- 替换 `endless` 卡片为 `survival`：更新 `key`、`desc`、`features`、`state:"ready"`。

## 九、平衡性初版数值（草案，待调）

- `goldStart: 150`（足以放 1~2 个基础塔 + 一座低配金矿）
- `enemiesPerWave: n => 5 + n`，`spawnInterval: wave => Math.max(0.9, 3.4 - wave*0.12)`
- `difficultyScale: wave => 1 + wave*0.12`
- 金矿：成本 60，每波 +8；升级 ×2 档
- 利息：每波持有金币 ×10%，封顶 80
- 波数：12 波 + 终局 Boss

---

## 十、风险与注意

- 敌人寻路：需保证单缺口可达、无死路；坡口不可被塔完全堵死（留通路过兵）。
- 高台与坡道建模：确认 `T_PLATEAU` / `T_RAMP` 的网格与渲染在 `survival` 大图上无穿模。
- 实时运营下 UI：商店面板需避免遮挡缺口视野（轻量化 / 可拖拽）。
- 经济膨胀：利息封顶与金矿升级需配合，防止后期金币溢出导致无挑战。
