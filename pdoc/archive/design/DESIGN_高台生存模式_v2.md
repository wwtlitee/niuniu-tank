> 本文档为「高台生存」模式的完整玩法与实现方案 **v2**。相对 v1 的关键变更（用户要求）：
> 1. **金矿改为每秒产金**（实时现金流，而非每波结算）。
> 2. **取消利息系统**（金矿产金与利息存在目标冲突，统一为金矿经济）。
> 3. **新增科技树**：用金币解锁/升级分支科技，强化运营决策深度。
> 4. **开局 30s 发育期**：倒计时内无敌人，玩家专注布局与经济起步。
> 5. **统一的炮台系统**：多种炮台类型，数据驱动，后续塔防（TD）模式可直接复用。

---

## 一、业务背景与定位

`endless`（无尽幸存）模式为开放大地图 + 自由构筑，长时间游玩易疲劳。

新「高台生存」改为**单点咽喉 + 实时运营 + 科技成长**的经典魔兽 RPG 生存图（参考《The Last Stand》《高地保安》《Monster Defense》）。玩家坐落于高台，仅一条窄下坡出口，默认石墙封口留缺口。在 30s 发育期内搭建经济与防御，之后迎击一波波进攻，靠**金矿现金流**与**科技树投资**滚雪球，守住核心并击杀最终 Boss。

**核心爽点**：
- 单入口 = 最易防守的集中 kill zone（The Last Stand「绿点」原则）。
- 控制塔 + 伤害塔协同（The Crossing「冰塔 + 死塔」原则）。
- 金矿每秒产金 + 科技树解锁，让「运营投资」成为核心决策（GemCraft / BTD 经济压力理论）。
- 高台水晶摧毁即败北，制造翻盘/崩盘张力。

---

## 二、地图设计（咽喉漏斗）

- 地图主体为一片**抬高的高台（plateau）**，占用图约下 1/2 区域，高度复用引擎常量 `PH = 1.6`（沿用 `T_PLATEAU` / `T_RAMP` / `rampDir` 逻辑）。
- 高台**仅一条 1~2 格宽的狭窄下坡**通往下方战场，为唯一出口。
- 出口底部**默认预置钢制石墙（`T_STEEL`），正中留 1 格缺口**——玩家不再建造墙体，缺口即咽喉 funnel。
- 高台为平整可建造区域；**核心建筑（水晶 / 鹰旗）** 置于高台中心偏后。
- 下方战场开阔，敌人从地图远端边界出生，向坡口集结、挤过缺口、登台扑核心。

**模块级影响**：`genMap` 新增 `survival` 专用分支，不再套用城市网格；复用既有高地 / 坡道网格与建模。

## 三、核心循环

### 阶段 0：发育期（开局 30s）
- 进入游戏即倒计时 `PREP_TIME = 30s`，**无敌人生成**。
- 玩家可自由建造炮台、金矿，并消耗金币解锁科技树。
- 倒计时结束 → 自动开启第 1 波（也可以手动提前结束发育期）。

### 阶段 1..N：实时运营 + 波次进攻
1. 敌波从远端生成 → 沿战场向坡口推进 → 挤过缺口 → 登台扑核心。
2. 玩家坦克 + 高台炮台在缺口 / 高台构成集中 kill zone 拦截。
3. 漏过缺口的敌人登台攻击核心；核心血量归零即败北。
4. 金矿**每秒**被动产金，玩家随时用金币建造 / 升级 / 点科技。
5. 清完一波后进入短间隙（无强制暂停），可继续补强，随后下一波自动开始。

**节奏设计**：发育期集中布局；之后压力来自「战斗中抢建 / 升级 / 点科技」的实时决策，而非静止等待。

## 四、经济公式（单一资源：金币）

| 来源 | 规则 | 说明 |
| :--- | :--- | :--- |
| 击杀收益 | 普通 10 / 快速 12 / 狙击 14 / 重装 22；精英 ×3；Boss 130 | 沿用现有掉落逻辑 |
| **金矿（每秒产金）** | 花金币建造，**每秒**被动产金（+2/s 基础，可升 6 级至 +14/s） | 用「即时战力」换「持续现金流」 |
| 科技树 | 消耗金币解锁 / 升级分支科技 | 投资未来战力 / 经济效率 |
| 波次奖励 | 每清完一波额外奖励（如 +25 + wave×5） | 鼓励速清，平滑现金流 |

**设计意图**：经济完全由「金矿产金速度」与「科技投资」驱动，取消利息以避免与金矿目标冲突。玩家需在「多造金矿滚雪球」与「多造炮台保命」之间权衡。

## 五、科技树系统（金币解锁 / 升级）

科技树为**分支树**，每个节点消耗金币解锁，解锁后可持续升级（多档）。已点科技全局生效，强化炮台、经济或玩家坦克。

### 5.1 科技分支总览

| 分支 | 名称 | 效果方向 | 升级档位 |
| :--- | :--- | :--- | :--- |
| A | **经济工程** | 金矿产金 +X%/档，金矿建造成本 -X%/档 | 5 档 |
| B | **武器研发** | 全体炮台伤害 +X%/档 | 5 档 |
| C | **精准制导** | 全体炮台射程 +X%/档 | 4 档 |
| D | **弹药供给** | 全体炮台射速 +X%/档 | 4 档 |
| E | **寒冰科技** | 冰冻塔减速幅度 +X%/档、减速塔伤害 +X%/档 | 3 档 |
| F | **装甲强化** | 玩家坦克血量 +X%/档、核心血量 +X%/档 | 4 档 |
| G | **指挥系统** | 玩家坦克伤害 +X%/档、移动速度 +X%/档 | 4 档 |

### 5.2 解锁规则
- **前置依赖**：部分高级分支需先点满前置（例如 D「弹药供给」需 B「武器研发」≥2 档）。
- **成本递增**：每档成本随档位指数上升（如 `cost = base * 1.6^level`）。
- **即时生效**：解锁 / 升级后立即影响全部已建 / 新建单位，无需重建。
- **UI**：独立「科技树」面板（快捷键 T），树状展示节点、档位、成本与依赖。

### 5.3 初版数值（草案，待平衡）
| 分支 | 每档增益 | 基础成本 | 成本系数 |
| :--- | :--- | :--- | :--- |
| A 经济 | +12% 产金 / -8% 造价 | 80 | 1.55 |
| B 武器 | +10% 伤害 | 100 | 1.6 |
| C 精准 | +8% 射程 | 90 | 1.55 |
| D 弹药 | +9% 射速 | 90 | 1.55 |
| E 寒冰 | +10% 减速 / +8% 冰伤 | 110 | 1.5 |
| F 装甲 | +10% 血量 | 100 | 1.6 |
| G 指挥 | +8% 坦伤 / +5% 移速 | 100 | 1.6 |

## 六、炮台系统（数据驱动，可复用于 TD）

统一抽象为 `TURRET_TYPES` 配置表，所有炮台共享索敌 / 射击 / 升级框架。生存模式与后续 TD 模式均从此表实例化，避免重复实现。

### 6.1 炮台类型（初版 6 种）

| ID | 名称 | 定位 | 基础造价 | 基础属性（Lv1） | 升级（Lv2/3）方向 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `mg` | 机枪塔 | 廉价单体持续 DPS，开局主力 | 50 | 伤害 6 / 射速 5/s / 射程 14 | 射速↑ / 伤害↑ |
| `cannon` | 加农炮塔 | AoE 溅射，清群 | 90 | 伤害 18 / 射速 1/s / 射程 16 / 溅射 4 | 溅射↑ / 伤害↑ |
| `frost` | 冰冻塔 | 范围减速（控制） | 80 | 伤害 3 / 射速 2/s / 射程 13 / 减速 35% | 减速↑ / 范围↑ |
| `sniper` | 狙击塔 | 超远射程、高单体，打重装/精英 | 120 | 伤害 40 / 射速 0.6/s / 射程 30 | 射程↑ / 穿透↑ |
| `pulse` | 脉冲塔 | AoE 眩晕（复用 EMP） | 140 | 伤害 10 / 射速 0.5/s / 射程 12 / 眩晕 1.2s | 眩晕↑ / 范围↑ |
| `tesla` | 电磁塔 | 连锁闪电，多目标 | 130 | 伤害 14 / 射速 1.5/s / 射程 15 / 连锁 3 | 连锁↑ / 伤害↑ |

> 说明：`frost` / `pulse` 偏控制，`mg` / `sniper` / `tesla` / `cannon` 偏输出，形成「冰控 + 集火」经典组合。

### 6.2 炮台等级与升级
- 每座炮台独立 **Lv1→Lv2→Lv3**，升级消耗金币，即时提升属性（不重建）。
- 升级增益叠加在科技树全局增益之上：`最终值 = 基础值 × 等级系数 × (1 + 科技增益)`。
- 炮台血条与等级标识在 UI 上可视化。

### 6.3 复用设计
- `TURRET_TYPES` 置于 `config.js`，含 `id / name / cost / stats / upgrade / color / desc`。
- `engine.js` 内 `spawnTurret(type)` / `upgradeTurret(t)` / `updateTurrets()` 为通用逻辑，生存与 TD 模式均调用。
- 后续 TD 模式只需复用同一份 `TURRET_TYPES` 与炮台运行框架，差异化仅在地图 / 波次 / 目标。

## 七、波次与敌人

- 沿用 `ENEMY_TYPES`（normal / fast / heavy / sniper）+ 精英词缀 + BOSS，难度按 `difficultyScale` 递增。
- 特殊波：`rush`（大量快速）、`armored`（多重装）、`frenzy`（狂暴）。
- **终局分支（第 15 波后）**：清完第 15 波并击杀最终 Boss 后，弹出结算选择：
  - **【胜利】**：结束游戏，记录战绩（推荐新手 / 速通玩家）。
  - **【无尽】**：不结束，继续生成第 16 波及以后，难度按 `difficultyScale` 持续指数增长，直至核心被摧毁。无尽阶段每 5 波再刷一次强化 Boss 作为里程碑。
- **发育期**：第 0 阶段 30s，之后 wave 1 开始。

### 初版波次曲线（草案）
| 波次 | 敌量 | 组成 | 备注 |
| :--- | :--- | :--- | :--- |
| 0（发育） | 0 | — | 30s 倒计时 |
| 1-3 | 6~10 | normal | 教学波 |
| 4-6 | 12~18 | normal+fast | 引入速度压力 |
| 7-9 | 18~26 | +heavy | 引入重装 |
| 10-12 | 24~34 | +精英 | 混编高压 |
| 13-14 | 30~40 | 特殊波 | rush / armored |
| 15 | Boss | 最终 Boss + 护卫 | 击杀后弹出「胜利 / 无尽」选择 |
| 16+ | ∞ | 无尽模式 | 难度指数增长，每 5 波强化 Boss |

## 八、胜负条件

- **胜（主动）**：清完第 15 波并击杀最终 Boss 后选择【胜利】。
- **胜（无尽坚持）**：无尽模式下坚持至任意时刻主动结算胜利；否则直至核心被摧毁判负。
- **负**：核心（水晶 / 鹰旗）被摧毁。
- **escalation（借鉴《高地保安》）**：高台外围塔被清空 → 核心解除护盾并刷超级兵，制造翻盘或崩盘张力。

## 九、技术实现与集成

### 9.1 `js/config.js`
- 将 `endless` 模式改为 `survival`（`key: "survival"`）。
- 新增参数：
  - `GRID`（建议 41 或 47）、`cameraY` / `cameraZ`、`fogFar`
  - `mapType: "survival"` 标志（用于 `genMap` 走专属分支）
  - `prepTime: 30`（发育期秒数）
  - `buildEnabled: true`、`buildTimer: 0`（实时运营）
  - `enemiesPerWave`、`spawnInterval`、`spawnCap`、`difficultyScale`、`goldStart`
  - `victoryWave: 15`（第 15 波后弹出【胜利 / 无尽】选择，无尽时难度加速）
  - `economy: { mineCost, mineBaseIncome, mineUpgradeIncome, mineMaxLevel: 6, waveClearBonus }`
  - `TECH_TREE`：科技树配置（分支、档位、成本、依赖）
  - `TURRET_TYPES`：炮台统一配置表（供生存 + TD 复用）

### 9.2 `js/engine.js`
- `genMap` 新增 `survival` 分支：高台 + 单坡口 + 默认石墙缺口 + 核心点位。
- **发育期**：`startPrep()` 启动 30s 倒计时，期间禁用敌人生成；倒计时结束调用 `startWave(1)`。
- **金矿每秒产金**：主循环 `loop` 中按 `dt` 累加 `game.gold += mineCount * income * dt`（挂接金矿实例）。
- **科技树**：`unlockTech(branch)` / `upgradeTech(branch)` 扣除金币、更新全局增益系数；新建 / 已建炮台属性实时重算。
- **炮台系统**：`spawnTurret(type)` / `upgradeTurret(t)` / `updateTurrets()` 通用框架，从 `TURRET_TYPES` 实例化。
- **商店 / 构筑**：`renderShop` 使用 `survival` 专属 `shopItems`（6 类炮台 + 金矿，无墙体）。
- **核心受击**：复用基地受击逻辑（`baseAlive` / `baseGroup`）绑定核心，被摧毁触发 `endGame`。
- **实时运营**：商店 / 科技面板可随时开关，不暂停游戏。

### 9.3 `js/home.js`
- 替换 `endless` 卡片为 `survival`：更新 `key`、`desc`、`features`、`state:"ready"`。

- `goldStart: 200`（足以放 1 座金矿 + 1~2 个基础塔）

- 核心血量：1000（受 F 装甲科技影响）

## 十一、风险与注意

- **敌人寻路**：需保证单缺口可达、无死路；坡口不可被塔完全堵死（留通路过兵）。
- **高台与坡道建模**：确认 `T_PLATEAU` / `T_RAMP` 渲染在 `survival` 大图上无穿模。
- **实时运营 UI**：商店 / 科技面板需避免遮挡缺口视野（轻量化 / 可拖拽）。
- **经济膨胀**：金矿升级与科技投资需配合，防止后期金币溢出导致无挑战；靠敌方血量 / 数量指数增长对冲。
- **科技树依赖**：前置依赖需 UI 明确提示，避免玩家点错分支卡死。
- **炮台复用**：`TURRET_TYPES` 抽象需足够通用，TD 模式接入时零改动或最小改动。
